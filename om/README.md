Operating model for simulation testing of protected species reference points. 

Installation
============
First, install `remotes` packages from CRAN:

    # Install packages
    install.packages("remotes")

Then install `om` directly from GitHub:

    # remotes command to get om from GitHub
    remotes::install_github("protected-species-management/operating-model")
